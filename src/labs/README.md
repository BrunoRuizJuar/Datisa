# Laboratorios

La plantilla de capítulo incluye un elemento identificado por `data-lab`. La navegación monta el laboratorio después de renderizar la lección.

- `bayes.js` contiene el posterior del ejemplo binario y su interfaz.
- `vector-model.js` contiene los datos sintéticos y los cálculos de k-NN y SVM. `vector.js` dibuja el gráfico y conecta los controles. La lección de SVM muestra la frontera desde el inicio.
